Global Electric Vehicle (EV) Analytics & Business Intelligence Suite

An end-to-end Business Intelligence (BI) and Data Analytics platform built for the rapidly expanding Global Electric Vehicle (EV) market. This repository provides an interactive dashboard, simulated SQL workbench, persona story scenes, clean dataset extraction schema, and integration guides for Python Flask & Tableau Desktop.

📌 Executive Summary & Problem Understanding

The global automotive landscape is rapidly transitioning from internal combustion engines (ICE) to electric powerplants. With growing environmental regulations, government subsidies, and advancements in battery technology (such as LFP, NMC, Solid-State, and Sodium-Ion), decision-makers require real-time visibility into market dynamics.

Key Business Challenges Solved:

Category Dominance: Identifying which vehicle categories (SUVs, Sedans, Hatchbacks, Two-Wheelers, Buses, Trucks) yield the highest sales volume and growth.

Battery Technology Adoption: Benchmarking driving range against battery capacity (kWh) and chemistry efficiency across diverse regions.

Competitive Intelligence: Evaluating global market share across leading manufacturers like Tesla, BYD, Volkswagen, Hyundai, Kia, and Tata Motors.

Geography & Production Strategy: Tracking regional manufacturing output across China, USA, Germany, Japan, South Korea, and India.

🎯 Target Persona Decision Stories

The platform provides tailored analytical workflows designed for three key stakeholders:

Scenario 1: Emily Johnson — EV Market Strategy Director

Focus: Category sales dominance, emerging market expansion, and premium product portfolio optimization (e.g., Solid-State deployment in high-range sedans).

Scenario 2: David Chen — Automotive Business Intelligence Manager

Focus: Competitive manufacturer benchmarking, vertical integration analysis, and global supply chain hub planning.

Scenario 3: Dr. Sarah Williams — Sustainable Mobility Research Analyst

Focus: Clean energy battery efficiency (km/kWh), lifecycle assessment, zero-carbon policies, and consumer satisfaction correlations.

🚀 Key Features

Interactive Executive Dashboard: Dynamic KPI summary cards with real-time reactive filtering across vehicle categories, battery chemistries, and manufacturing regions.

Dynamic Visualization Engine: Built using Chart.js to render category volume bar charts, brand distribution, battery tech adoption share, and efficiency scatter plots (Range vs. Battery Capacity).

In-Memory SQL Workbench: Simulated live SQL query editor executing queries over SQLite/PostgreSQL modeled ev_market_data tables with query latency execution benchmarks.

Fully Responsive UI: Mobile-first Tailwind CSS UI optimized for desktop monitors, tablets, and handheld devices.

Flask & Tableau Integration Ready: Architectural blueprints and code samples for serving dynamic data via Python Flask REST APIs and embedding Tableau Server JavaScript views.
