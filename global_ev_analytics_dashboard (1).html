Project Architecture & Kaggle Data Pipeline

Step-by-step documentation from Kaggle dataset ingestion to Tableau dynamic embedding and Python Flask web service deployment.

1

Data Extraction (Kaggle Dataset)

Dataset acquired from Kaggle (tharishreddy22/electric-vehicle-market-classification-dataset) and mapped directly to SQLite database schemas.

CREATE TABLE ev_market_data (
  id INT PRIMARY KEY,
  model VARCHAR(100),
  category VARCHAR(50),
  battery_tech VARCHAR(50),
  sales_units INT
);
2

Tableau & Data Prep Engine

Connected database directly via PostgreSQL connector to Tableau Desktop/Server. Calculated fields created for Range Efficiency (Driving_Range / Battery_Capacity) and Price per kWh.

  • Calculated Field 1: Efficiency Index
  • Calculated Field 2: YoY Market Growth %
  • Tableau Server Embed JS API integration
3

Flask Back-End API Server

Python Flask server acts as the middleware serving API routes to query database tables and serve dynamic payloads to web frontend interfaces.
